# Web-Dev

Practical coursework, laboratory experiments, UI implementations, and study materials documenting my web development learning journey as a Computer Science & Engineering undergraduate.

---

## Purpose

This repository serves as a structured archive of my hands-on practice in foundational web technologies. It documents my progression from core HTML syntax and semantic page structures to CSS styling, form handling, basic JavaScript DOM manipulation, and integrated multi-section webpage layouts.

---

## Contents

The repository is organized by topic and module:

- **`assets/`** — Graphic assets, branding logos, and image media referenced across lab practicals and UI layouts.
- **`CSS/`** — CSS styling demonstrations, box model implementations, styling selectors, and external stylesheet integration (`style.css`).
- **`forms/`** — HTML form input exercises, including student registration, employee records, business contact pages, and styled login interfaces.
- **`JavaScript/`** — Client-side scripting fundamentals covering DOM element access, event listeners, basic arithmetic input processing, conditional logic, and dynamic page style updates.
- **`practicals/`** — Structured lab practicals covering core HTML topics: text formatting tags, ordered and unordered lists, hyperlinks, tabular data representations, and multimedia embeds (`audio`, `video`, `iframe`).
- **`projects/`** — Multi-section webpage implementations, including a semantic blog layout, a departmental webpage, a complete webpage showcase, and a responsive Spotify Web Player UI clone.
- **`Study Guide/`** — Comprehensive reference materials, tag cheat sheets, attribute guides, and practical study documents formatted in Markdown, HTML, and PDF.

---

## Technologies Used

- **HTML5** — Semantic page architecture, forms, tables, and media embeds
- **CSS3** — Custom layouts, typography, styling, and UI components
- **JavaScript (Vanilla)** — DOM manipulation, event handling, and client-side interactions
